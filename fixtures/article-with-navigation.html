Building a deterministic parser benchmark

CONTENT_SENTINEL_ALPHA Measuring text extraction strategies requires stable input documents. Each candidate must receive the same captured HTML snapshot, otherwise changing network responses introduce confounding effects.

CONTENT_SENTINEL_BETA A useful evaluation examines whether the extractor retains important technical details, mathematical notation, code examples, table entries and document structure. Fewer output bytes do not establish better quality for semantic retrieval.

CONTENT_SENTINEL_GAMMA We preserve this source as an immutable fixture so tests can compare extraction quality across software upgrades. Measurements should report important content coverage and irrelevant boilerplate leakage separately.
